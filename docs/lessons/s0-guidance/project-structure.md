## お手本作品『LUMEN』

---

授業のテーマは、3Dで制作されたお手本作品『LUMEN』からピックアップしています。
セルルック調の3Dアクションアドベンチャーで、塔を探索して3つの灯を灯し、最奥のボスを倒すとクリアです。

『LUMEN』は**各章の内容をすべて使った集大成**です。各単元では、そこからテーマを1つ取り出し、学びやすい形に組み直した演習シーンを使います。

| | |
| --- | --- |
| **場所** | `Assets/_DemoGame/` |
| **使い方** | 完成形の参考展示。各単元の技術が、完成した作品のどこに使われているかを見る。**授業中に編集はしません** |
| **演習** | 各単元の演習シーン（`Assets/Application/` の下）で自分の手を動かします |
