# ２−４★★★☆☆　小さな敵を足して、ボスとは別の道から追わせる

[課題について](../index.md) ｜ [2章の課題](index.md) ｜ 関連資料：[キャラクターAI](../../s2-ai-state/character-ai.md)

---

今のステージでは、狭い隙間へ逃げるとボスは遠回りします。そこに体の小さな敵がいれば、隙間も安全地帯ではなくなります。**同じステージに小さな敵を足し、小さな敵は狭い隙間を、ボスは広い通路を通って追いかける**ようにしてください。

### 推奨条件

---

```text
・EnemyBoss の Prefab Variant などで、体の小さな敵を作る
・元の EnemyBoss.prefab は上書きしない
・小さな敵の Agent Type を Humanoid にする
・Stage に Humanoid 用の NavMesh Surface を追加して Bake する
・Agent の Radius、Height と、攻撃に使う距離を小さな体に合わせる
・同じ場所を目指しても、体格によって経路が変わることを確認する
```

作業用シーンの準備は[講義資料の演習の準備](../../s2-ai-state/character-ai.md)を参照してください。完成見本のシーンや共通素材の元ファイルは上書きしません。

### 提出方法

---

小さな敵とボスが別の道から追いかけてくる動画をslackに提出してください。課題番号と、2つの NavMesh Surface の設定が分かるスクリーンショットを添えてください。

### ヒント

---

NavMesh は Agent Type ごとに別のデータです。`Boss` の Surface を残したまま、もう1つ Surface を追加します。

小さな敵が止まったままのときは、講義資料の「[不具合を分けて調べる](../../s2-ai-state/character-ai.md)」の表で確認しましょう。`Stopping Distance` と `Attack Range` はボスの体格に合わせた値です。そのままでは、小さな敵の攻撃が届かない位置で止まります。
