# ２−１２★☆☆☆☆　Mermaid でクラス図を書いてみる

[課題について](../index.md) ｜ [2章の課題](index.md) ｜ 関連資料：[集約・合成とクラス図](../../s2-ai-state/composition-class-diagram.md)

---

クラス図を Mermaid 記法で書く練習です。講義資料の「C# での書き分け」に出てきた `Hero` のコードを、**Mermaid 記法でクラス図にしてください**。[Mermaid Live Editor](https://mermaid.live/) で図を確かめながら進めます。

### 進め方

---

1. [Mermaid Live Editor](https://mermaid.live/) を開き、左の Code 欄を空にする。
2. 下のひな形を貼り付け、右に図が表示されることを確かめる。
3. `TODO` の部分を書き足す。

```text
classDiagram
    class Hero {
        -Inventory _inventory
        -IWeapon _weapon
        +Equip(IWeapon weapon)
        +Attack() int
    }
    class Inventory {
        +int Potions
    }
    class IWeapon {
        <<interface>>
        +int Power
    }

    %% TODO：Hero と Inventory の線（合成）
    %% TODO：Hero と IWeapon の線（集約）
    %% TODO：IWeapon を実装した Sword と Staff を足し、実現の線を引く
```

### 推奨条件

---

```text
・ひな形の TODO をすべて書き、Mermaid Live Editor でエラーなく表示する
・合成、集約、実現の線を正しい向きで引く
・Sword と Staff に、それぞれ Power を書く
```

### 提出方法

---

Mermaid のコードと、Mermaid Live Editor で表示した図のスクリーンショットをslackに提出してください。課題番号を添えてください。

### ヒント

---

線の書き方は、講義資料の[関係の線](../../s2-ai-state/composition-class-diagram.md)の表にあります。ひし形は全体（持ち主）の側、三角は約束（Interface）の側に付きます。

図が表示されず赤いエラーが出たら、直前に書いた1行を消して、1行ずつ足し直すと原因を見つけやすくなります。
