# ２−３★★★☆☆　段差を飛び降りる近道を、NavMesh Linkで作る

[課題について](../index.md) ｜ [2章の課題](index.md) ｜ 関連資料：[キャラクターAI](../../s2-ai-state/character-ai.md)

---

高台からプレイヤーを見下ろしたボスが、わざわざ坂まで戻ってから下りてくると、間の抜けた印象になります。通常の面だけではつながらない場所を **NavMesh Link** で接続し、**ボスが高台から飛び降りて近道する**ようにしてください。

### 推奨条件

---

```text
・ステージに、坂で上れる高台を追加して Bake する
・高台の高さは、Step Height（0.75 m）より高くする
・坂の傾きは Max Slope（45 度）以内にし、幅はボスが通れる大きさにする
・NavMesh Link の Agent Type を Boss にする
・高台から下りる方向だけ通れるように、Bidirectional を OFF にする
・Link がないときとあるときで、ボスの経路が変わることを確認する
```

作業用シーンの準備は[講義資料の演習の準備](../../s2-ai-state/character-ai.md)を参照してください。完成見本のシーンや共通素材の元ファイルは上書きしません。

### 提出方法

---

Link がないときとあるときで、ボスが高台から下りる経路を比べた動画をslackに提出してください。課題番号と、Link を一方通行にした理由を添えてください。

### ヒント

---

まず `Show NavMesh` で高台の上と坂に面があるか確認します。ボスの半径は 1.1 m なので、高台の縁と壁際には面がありません。Link の両端は、この面の近くに置きましょう。

飛び降りる見た目のアニメーションは必須ではありません。今回は「経路としてつながること」を確認します。
