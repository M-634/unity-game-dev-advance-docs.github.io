# ２−９★★★★☆　離れた相手へ一直線に突進する

[課題について](../index.md) ｜ [2章の課題](index.md) ｜ 関連資料：[Stateパターン](../../s2-ai-state/state-pattern.md)・[キャラクターAI](../../s2-ai-state/character-ai.md)

---

近距離の振り下ろしだけでは、ボスから離れていれば安全です。**中距離では一直線に突進する攻撃を足し、距離によって攻撃を使い分ける**ようにしてください。壁を突き抜けず、途中で怯んでも速度の設定が元に戻るようにします。

### 推奨条件

---

```text
・IState を実装した ChargeState を Scripts/Enemy/States/ に作る
・追跡中に、Inspector で決めた距離の範囲にプレイヤーがいれば突進を始める
・突進には専用のクールダウンを持たせ、連続で使わないようにする
・予告の後に進行方向を固定し、途中で曲がらない
・NavMesh.Raycast で壁の手前の地点を求め、そこまで進む
・位置を動かすのは NavMesh Agent だけにする（Transform を直接動かさない）
・Agent の Speed などを変えた場合は、OnExit で元に戻す
・1回の突進で、ダメージは1回だけ与える
```

作業用シーンとスクリプトの準備は[講義資料の演習の準備](../../s2-ai-state/state-pattern.md)を参照してください。完成見本のシーンや共通素材の元ファイルは上書きしません。

### 提出方法

---

距離によって攻撃が変わる動画と、壁の手前で突進が止まる動画をslackに提出してください。課題番号と、変更したコードを添えてください。

### ヒント

---

`NavMesh.Raycast` にも Agent Type を指定します。[SamplePosition の注意](../../s2-ai-state/character-ai.md)と同じように、`NavMeshQueryFilter` を渡しましょう。

ボスの `Stopping Distance` は 3.2 m、`Acceleration` は 12 です。そのままだと、目的地の手前で止まり、なかなか速度も上がりません。突進の間だけ値を変えるなら、`EnemyController` に変更用のメソッドを足し、`OnEnter` と `OnExit` で対にして呼びます。

`PursueState` の中で、振り下ろしと突進のどちらの条件を先に調べるかも考えましょう。
