# ２−１３★★★☆☆　ボスのスクリプトを、クラス図に描き起こす

[課題について](../index.md) ｜ [2章の課題](index.md) ｜ 関連資料：[集約・合成とクラス図](../../s2-ai-state/composition-class-diagram.md)

---

[２−５](s2-5.md)では敵の動きを状態遷移図にしました。状態遷移図は「どの順番で動くか」を表しますが、「どのクラスが何を持っているか」は表しません。今回は、講義資料のクラス図とボスの**スクリプトを見比べながら、Mermaid 記法でクラス図に描き起こしてください**。

講義のクラス図は `EnemyController` を中心に描き、ボスだけの部分を省略しました。この課題では、省略した**ボスの怒りと無敵の仕組み**を描き足します。

### 進め方

---

1. 下のひな形を [Mermaid Live Editor](https://mermaid.live/) に貼り付ける。講義のクラス図から、ボスに関係する部分だけを残したものです。
2. 下の表のファイルを開き、`TODO` のクラスのフィールドとメソッドを書き足す。
3. コードの中で `new` している場所と、コンストラクタの引数を探し、`TODO` の線を書き足す。

| 開くファイル（`Assets/Application/Section2-AIState/Scripts/`） | 見るところ |
| --- | --- |
| `Enemy/BossController.cs` | フィールド、`CreateStates`、`OnDamaged` |
| `Enemy/BossParameters.cs` | `BossParameters` と、状態ごとの設定のクラス |
| `Enemy/States/AngryState.cs` | コンストラクタの引数、`OnEnter` で持ち主の何を呼んでいるか |
| `Enemy/States/InvincibleState.cs` | コンストラクタの引数 |

### 推奨条件

---

```text
・ひな形の TODO をすべて埋め、Mermaid Live Editor でエラーなく表示する
・継承、実現、合成、集約（または関連）の線を、それぞれ1本以上使う
・各クラスの箱には、図の目的に関係するフィールドとメソッドだけを書く
・アクセス修飾子（+ - #）を付ける
```

### 提出方法

---

Mermaid のコードと、Mermaid Live Editor で表示した図のスクリーンショットをslackに提出してください。課題番号を添えてください。

### ヒント

---

`InvincibleState` は `BossParameters` を自分で `new` していません。誰かが作ったものを、コンストラクタで受け取っています。

[２−１０](s2-10.md)に取り組んでいる人は、自分で足した状態もこの図に描き加えましょう。状態遷移図とクラス図の両方があると、ほかの人にボスの仕組みを説明しやすくなります。
