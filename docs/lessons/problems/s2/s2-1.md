# ２−１★☆☆☆☆　数値だけで、性格の違うボスを2種類作る

[課題について](../index.md) ｜ [2章の課題](index.md) ｜ 関連資料：[キャラクターAI](../../s2-ai-state/character-ai.md)

---

同じコードのボスでも、判断に使う数値が違えば、遊んだときの印象は変わります。**スクリプトを変更せず、Inspector の数値だけで性格の違うボスを2種類作ってください。**「しつこい」「隙が大きい」のように、それぞれの性格を言葉で表せるようにします。

### 推奨条件

---

```text
・スクリプトは変更せず、EnemyBoss の Inspector の値だけを変える
・性格の違うボスを2種類考え、それぞれに名前を付ける
・Detect Range、Lose Range、Attack Interval Time のうち、2つ以上を変える
・Lose Range は Detect Range より大きくする
・Attack Range は NavMesh Agent の Stopping Distance より大きくする
```

作業用シーンの準備は[講義資料の演習の準備](../../s2-ai-state/character-ai.md)を参照してください。完成見本のシーンや共通素材の元ファイルは上書きしません。

### 提出方法

---

2種類のボスの動きの違いが分かる動画をslackに提出してください。課題番号、それぞれの名前と性格、変更前後の値を添えてください。

### ヒント

---

`開発用 > Draw Debug` が ON なら、足元の円で距離を確認できます。Play 中に変えた値は、再生を止めると元に戻ります。よい値が見つかったら、書き留めてから止めましょう。
