# １−７★★★☆☆　右クリックの間だけ、肩越しの構えカメラにする

[課題について](../index.md) ｜ [1章の課題](index.md) ｜ 関連資料：[Cinemachineとカメラ制御](../../s1-character-camera/cinemachine.md)

---

弓や魔法で狙いをつけるゲームでは、**構えている間だけカメラが肩越しに寄ります。**
右クリックを押している間だけ、肩越しの構えカメラに切り替えてください。

### 推奨条件

```text
・Week01-Animation_Sample を複製したシーンで作業する（元のシーンは保存しない）
・Body を 3rd Person Follow にした Virtual Camera（CM_Aim）を足す。FOV は CM_TPS より狭くする
・右クリックを押している間だけ CM_Aim の Priority を上げる。離したら戻す
・構えている間も、マウスで狙う向きを変えられる
・FPS のときは構えカメラにしない（どちらを優先するかは自分で決めてよい）
```

### 提出方法

構える → 狙いながら歩く → 構えを解く、を映した動画をslackに提出してください

### ヒント

```text
・右クリックは、配布の入力アクションを変えなくても Mouse.current.rightButton.isPressed で読める
・3rd Person Follow の Shoulder Offset で、右肩の上にカメラを置く
・3rd Person Follow は、Follow の対象の向きがそのままカメラの向きになる。DemoPlayer の子に空の GameObject を足し、それをマウスで回す
・Priority は CM_TPS（20）より高い値にすると映る
・今が FPS かどうかは、CameraModeSwitcher の Mode で分かる
・3rd Person Follow には Camera Collision Filter があり、Collider の拡張なしで壁を避けられる
```
