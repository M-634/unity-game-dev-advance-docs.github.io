# １−３★★★★★　走りながら上半身だけで攻撃する

[課題について](../index.md) ｜ [1章の課題](index.md) ｜ 関連資料：[補足：アニメーションブレンド](../../s1-character-camera/animation-blend.md)

---

今の `AC_Player` は Base Layer だけなので、走りながら攻撃すると**足が止まります。**

**走っている最中に攻撃しても、足が走りのまま動き続ける**ようにしてください。

### 推奨条件

```text
・Avatar Mask で上半身だけを有効にしたものを作り、AnimationRigging/Animations/ に置く
・AC_Player に上半身用の Layer を追加し、そこに攻撃を置く
・課題１−１の Animation Event は、上半身の Layer で再生しても呼ばれる
・止まっているときの攻撃は、今までどおり全身で攻撃してもよい（しなくてもよい）
```

### 提出方法

**走りながら攻撃して、足が走りのまま動き続けている**ことがわかる動画をslackに提出してください
