# １−１★★☆☆☆　別のモーションで、振り下ろした瞬間に当てる

補足資料「[モーションの取り込みとコピー](../../s1-character-camera/motion-import.md)」の `Enemy_Attack_1` の例を参考に、**RPG Animations Pack FREE の別の攻撃モーション**に差し替えてください。

モーションが変わると、**当たる瞬間も変わります。** 自分でコマ送りして、イベントの位置を決め直してください。

### 推奨条件

```text
・授業で使っていない攻撃モーションを使う（例：One Hand Up/Attack_A や Attack_B の中から1つ）
・Rig が Humanoid / Copy From Other Avatar になっていることを確認する
・Clip を .anim にコピーして AnimationRigging/Animations/ に置き、AC_Player の Attack ステートに入れる
・Animation Event で PlayerAttack の判定（ApplyDamage）を呼ぶ。ボタンを押した瞬間には呼ばない
・判定の球（DebugShapes の表示）が、杖が振り下ろされた瞬間に出る
```

### 提出方法

攻撃を**3回以上**出し、**判定の球が振り下ろしの瞬間に出ている**ことがわかる動画と、
Animation ウィンドウで**イベントを置いたフレーム**が映ったスクリーンショットをslackに提出してください
