# １−５★★★★★　坂道や段差で、足を地面に合わせる

[課題について](../index.md) ｜ [1章の課題](index.md) ｜ 関連資料：[IKとFK、AnimationRigging](../../s1-character-camera/ik-fk.md)

---

モーションは平らな地面の上で作られています。坂道や階段の上に立たせると、**片足が宙に浮いたり、地面にめり込んだり**します。

**坂道・段差の上に立ったときに、両足がちゃんと地面についている**状態にしてください。

何が「ちゃんとついている」なのかは、自分で決めてください。

### 推奨条件

```text
・坂道（傾けた Cube）と段差（階段状に並べた Cube）を用意する
・その上で待機しているときに、両足が地面から浮いて見えない／めり込んで見えない
・歩き出したときに、足の動きが不自然にならない（止まるときと動くときの切り替えも含めて）
・箱押し（Rig_Hands）と、手を伸ばす動き（Rig_Reach）を壊さない
・「どうなっていたら足がついていると言えるか」を、自分の言葉で定義して提出時に書く
```

### 提出方法

坂道と段差の上で**待機・歩き**をしている様子を、**足元が見える角度**で映した動画と、上で決めた定義（2〜3 行）をslackに提出してください

### ヒント

```text
・Rig_Hands と同じように、脚の Two Bone IK を入れた Rig を足す（Thigh → Leg → Foot）
または
・AC_Player の IK Pass をオンにして、OnAnimatorIK で AvatarIKGoal.LeftFoot / RightFoot を動かす
・どちらでも、足の上から下へ Physics.Raycast を飛ばし、当たった位置に足の目標を置く
・腰（Hips）を下げないと、低い側の足が届かない。体全体をどれだけ下げるか
```
