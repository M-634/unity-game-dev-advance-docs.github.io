# １−６★★☆☆☆　高台に上がったら、引きのカメラに切り替える

[課題について](../index.md) ｜ [1章の課題](index.md) ｜ 関連資料：[Cinemachineとカメラ制御](../../s1-character-camera/cinemachine.md)

高台の上では、周りの景色を見渡したくなります。
**プレイヤーが高台に上がったら、少し引いて見下ろすカメラ**に切り替え、降りたら元に戻してください。

### 推奨条件

```text
・Week01-Animation_Sample を複製したシーンで作業する（元のシーンは保存しない）
・シーンに高台を置く（Cube を並べたものでよい）
・CM_TPS とは別に、引きの Virtual Camera（CM_Wide など）を1台足す。位置は固定し、Look At で DemoPlayer を見る
・高台の上に Is Trigger の Box Collider を置き、入ったら CM_Wide の Priority を上げ、出たら下げる
・切り替わりは一瞬で飛ばない（Brain の Blend でつながる）
```

### 提出方法

高台に上がる → 引きのカメラになる → 降りる → 元のカメラに戻る、までを映した動画をslackに提出してください

### ヒント

```text
・CM_Wide の作り方は、講義資料の Step 4（CM_Top）と同じ。Body を Do nothing、Aim を Composer にする
・Priority は CM_TPS（20）より高い値にすると映る
・Trigger の判定は OnTriggerEnter / OnTriggerExit。相手が Player タグかどうかで絞る
・この切り替えだけ Blend を長くしたいときは、Brain の Custom Blends を使う
```
