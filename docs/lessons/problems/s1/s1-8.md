# １−８★★★★☆　追従カメラを自分で書いて、Cinemachine と比べる

[課題について](../index.md) ｜ [1章の課題](index.md) ｜ 関連資料：[Cinemachineとカメラ制御](../../s1-character-camera/cinemachine.md)

---

授業では、追いかけるカメラをスクリプトを書かずに作りました。今度は Cinemachine を使わず、**同じ動きを自分のスクリプトで書いて**ください。
そのうえで、Cinemachine と比べて、**何がまだ足りないか**を言葉にしてください。

### 推奨条件

```text
・Cinemachine_Work を複製したシーンで作業する（Cinemachine は使わない。Main Camera に Brain を付けない）
・Main Camera に自分のスクリプトを付け、Target を決めた距離から追いかけて、Target のほうを向く
・Target が折り返すとき、カメラが遅れてついてくる（Damping にあたる動き）
・Wall を Target の通り道の手前に置いても、カメラが壁の向こうに行かない
・壁から離れたとき、カメラがガクッと戻らない（なめらかに戻す）
・提出時に「Cinemachine と比べて、まだ足りないこと」を3つ書く
```

### 提出方法

Target を追いかける様子と、壁の裏を通るときの様子を映した動画と、足りないこと3つをslackに提出してください

### ヒント

```text
・カメラは LateUpdate で動かすと、Target が動いたあとの位置を追える
・遅れは Vector3.SmoothDamp で「今の位置」を「目標の位置」に近づけると作れる
・壁は Physics.SphereCast を Target からカメラの置きたい位置へ飛ばして探す。当たったら、その手前にカメラを置く
・Physics.SphereCast の layerMask 引数で、当たる対象を絞れる（Target 自身に当たらないようにする）
・比べる相手は、講義資料の Step 2〜3 と「発展：壁を避ける」で作ったカメラ
```
