# １−８★★★★☆　手書きのカメラに壁の回避を入れて、Cinemachine と比べる

[課題について](../index.md) ｜ [1章の課題](index.md) ｜ 関連資料：[Cinemachineとカメラ制御](../../s1-character-camera/cinemachine.md)

---

授業では、壁抜けを1つだけ手で直してみました。今度は `SimpleFollowCamera` に、**壁の回避をきちんと入れて**ください。
そのうえで、Cinemachine の Collider と比べて、**何がまだ足りないか**を言葉にしてください。

### 推奨条件

```text
・CameraControl_Start の SimpleFollowCamera を書き換える（Cinemachine は使わない）
・壁・柱・通路のどこでも、カメラが壁の向こうに行かない
・プレイヤー自身には当たらない
・壁から離れたとき、カメラがガクッと戻らない（なめらかに戻す）
・提出時に「Cinemachine の Collider と比べて、まだ足りないこと」を3つ書く
```

### 提出方法

壁・柱・通路を回る様子を映した動画と、足りないこと3つをslackに提出してください

### ヒント

```text
・Physics.SphereCast の layerMask 引数で、当たる対象を絞れる
・なめらかに戻すには、Mathf.SmoothDamp で「今の距離」を「目標の距離」に近づける
・カメラは LateUpdate で動かすと、プレイヤーが動いたあとの位置を追える
```
