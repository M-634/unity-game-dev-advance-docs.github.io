# １−４★★★☆☆　手を伸ばして押すスイッチを作る

[課題について](../index.md) ｜ [1章の課題](index.md) ｜ 関連資料：[IKとFK、AnimationRigging](../../s1-character-camera/ik-fk.md)

---

篝火や灯火と同じように、**E を押すと右腕が伸びて、手が届いた瞬間に反応する**スイッチを新しく作ってください。

押すモーションは使いません。**DemoPlayer の `Rig_Reach`（右腕の IK）をそのまま使います。**

### 推奨条件

```text
・スイッチは Cube で可。IInteractable を実装した新しいスクリプトを作る（namespace は Section1.AnimationRigging）
・Interact の中で PlayerStaffReach.ReachOrRun を使い、手を置く位置はスイッチの表面にする
・手が届いた瞬間（ReachOrRun に渡した処理が呼ばれたとき）に、スイッチの色が変わる
・押したあとはもう一度押せない、または押すたびに切り替わる（どちらかを選ぶ）
・壁の高い位置・低い位置にも1つずつ置き、どちらでも手が表面に届く
```

### 提出方法

高い位置と低い位置のスイッチを押す様子を**横から**映した動画をslackに提出してください
