# １−９★★★★★　敵を見ながら戦えるロックオンカメラを作る

[課題について](../index.md) ｜ [1章の課題](index.md) ｜ 関連資料：[Cinemachineとカメラ制御](../../s1-character-camera/cinemachine.md)

---

アクションゲームの多くは、**敵をロックオンすると、プレイヤーと敵の両方が画面に収まる**カメラになります。
シーンに的（敵の代わりの Cube など）を置き、ボタンでロックオン／解除できるカメラを作ってください。

### 推奨条件

```text
・AnimationRigging_Sample を複製したシーンで作業する（元のシーンは保存しない）
・ロックオン中は、プレイヤーと的の両方が画面に入り続ける
・プレイヤーが的の周りを回っても、的を見失わない
・ロックオンの開始と解除で、カメラが一瞬で飛ばない
・的が複数あるとき、どれをロックオンするかの決め方は自分で決める（近い順・画面の中央に近い順など）
・プレイヤーの移動の基準（カメラの向き）が、ロックオン中も自然になっている
```

### 提出方法

的の周りを回りながら、ロックオン → 解除 → 別の的にロックオン、を映した動画をslackに提出してください

### ヒント

```text
・Cinemachine Target Group に、プレイヤーと的を入れる
・Virtual Camera の Look At に Target Group を入れ、Aim を Group Composer にする
・ロックオンの開始と解除は、ロックオン用の Virtual Camera の Priority を上げ下げするだけでよい
```
